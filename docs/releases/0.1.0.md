# QA 0.1.0 release preparation

Status: candidate; the tag and release have not been published.

The first tagged release provides the existing `qa` commands, strict gate
verification and adoption schema version 1. It requires PHP 8.5 and retains
PHPUnit `^10.5 || ^11.5 || ^13.0` support. No command or skip behavior changes.

The Coding Standards requirement is now `^1.1`, without a development-branch
alternative. The package explicitly uses stable minimum stability and needs
no custom Composer repository. Consumers can retain their own stable policy.

## Verification on 2026-09-30

Using PHP 8.5.9 and Composer 2.10.3 with an isolated Composer home:

- A fresh `composer update --no-scripts --prefer-dist --no-interaction`
  resolved 56 packages from Packagist, all with stable versions and none using
  a path repository. The result included Coding Standards 1.1.0, PHPUnit
  13.3.6, PHPStan 2.2.16 and PHPCompatibility 9.3.5.
- `composer validate --strict` passed.
- `composer qa` passed strict doctor, coding standards, static analysis and
  15 tests with 68 assertions. No QA gate was skipped.
- Composer reported no security vulnerability advisories for this resolution.

The generated development lock remains untracked under the existing library
policy. This verification describes the tested resolution, not a frozen
transitive dependency set for every future install. PHPUnit 10.5 and 11.5 were
not rerun as part of this dependency-only preparation.
