# QA 0.1.6

`sympress.preparedSql` (WordPress profile) now also checks untyped
`global $wpdb` and `$GLOBALS['wpdb']` receivers, the most common WordPress
pattern, which were silently skipped before. Core table-name properties such as
`$wpdb->prefix`, `$wpdb->base_prefix` and `$wpdb->posts` count as constant inside
interpolated or concatenated SQL, so `"FROM {$wpdb->prefix}things"` templates no
longer need ignores. Consumers with dynamic SQL on `global $wpdb` may see new
findings; fix them with `wpdb::prepare()` or a reviewed local ignore.

`qa --version` reports the installed package version from Composer instead of a
hardcoded string.

Also included since 0.1.5: an opt-in `config/phpstan/app.neon` profile with the
kernel's service rules (see `docs/adoption.md`), and CI pinned to
`sympress/workflows` v1.3.2.
