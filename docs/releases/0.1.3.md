# QA 0.1.3

Require Symfony Process 8.0.5 or newer to exclude
[CVE-2026-24739](https://github.com/advisories/GHSA-r39x-jcww-82v6)
from consumer dependency resolution. The command and strict-mode contracts are unchanged.

Update `sympress/qa` with Composer and review the resulting lockfile. This fixes
the package's allowed dependency range; it does not establish that an installed
consumer was vulnerable.
